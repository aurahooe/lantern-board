# The Hour Desk (Lantern)

A small public writing board.

- Sign in with email + password (Supabase Auth).
- Slips save to Postgres. Private by default.
- Flip **Hang on the public wall** and the slip appears for everyone.
- The masthead edition reprints from `lantern_hours` (filled every hour by a Grok automation).

Live source: this repo. Point Vercel or any static host at the root.
